
  # Mauqette Mbolo Green

MBOLO GREEN est une plateforme web dédiée à la sensibilisation et à l’engagement autour de l’économie verte au Gabon.

Cette maquette UI/UX propose une expérience utilisateur fluide et accessible, incluant :

une page d’accueil immersive ;

une carte interactive des initiatives écologiques ;

un centre de ressources éducatives ;

des défis citoyens gamifiés ;

un profil utilisateur avec suivi des actions et badges.

Le projet adopte une identité visuelle inspirée des paysages forestiers gabonais et met l’accent sur l’innovation, la participation citoyenne et le développement durable.
